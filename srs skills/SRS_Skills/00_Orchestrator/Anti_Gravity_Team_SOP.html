Square Root SEO: Anti-Gravity SOP

The official execution manual for using SRS Skills with Anti-Gravity.

🚀 1. Getting Started: The Setup

Welcome to the SRS Skill Ecosystem. This folder contains the collective brainpower of Square Root SEO, organized into specific "Skills". Anti-Gravity is your AI agent, but these skills are its instructions.

How to Load Your Workspace
  1. Download the latest SRS_Skills.zip file provided by Punit.
  2. Extract/unzip the folder on your computer.
  3. Open Anti-Gravity.
  4. Set your active workspace in Anti-Gravity to the extracted SRS_Skills folder. This ensures Anti-Gravity can read every single standard, rule, and workflow we use at the agency.

Note for Admins: Whenever skills are updated, distribute a new ZIP file to the team. Team members should delete the old folder and replace it with the new unzipped folder.

👑 2. The Golden Rule: The Orchestrator First

At Square Root SEO, a generic prompt produces generic output. If you just ask Anti-Gravity to "write a blog post" or "make a graphic," it will give you average, basic results.

To get agency-quality output, you must ALWAYS start with the Prompt Orchestrator. The Orchestrator acts as the factory floor manager—it listens to your brief, figures out which department is needed, and engineers the perfect prompt.

Anti-Gravity, load the srs-prompt-orchestrator skill. I have a new task for [Client/Project Name]. Here is my brief: [Insert your raw instructions, ideas, or client brief here]. Please formulate the perfect prompt for this and tell me which skills we need to execute it.

🔄 3. The Standard 3-Step Execution Workflow

Every single task you do in Anti-Gravity follows these three steps. Do not skip them.

Step 1: The Brief Intake

You receive a task (e.g., "We need an Instagram carousel for UniPride"). You paste that brief into Anti-Gravity using the Orchestrator prompt above.

Step 2: The Prompt Engineering

Anti-Gravity reads the srs-prompt-orchestrator skill and generates a structured prompt using our 7-part architecture (Role + Context + Task + Constraints + Format + Examples + Quality Gate). It will also tell you which specific department skill to load (e.g., graphic-designer-srs).

Step 3: The Execution

Now that you have the perfect prompt, you tell Anti-Gravity to execute it using the required skill.

Perfect. Now, load the [Skill Name] skill and execute the prompt you just generated.

💼 4. Department Playbooks

Here is how the workflow looks in action for specific roles.

🎨 Graphic Designers

Use Case: Designing a social media graphic or website hero image.

Relevant Skill: graphic-designer-srs

  • Ask the Orchestrator to draft the prompt based on your brief.
  • Trigger the Graphic Designer skill.
  • Anti-Gravity will use generate_image for AI visuals, and use the browser to open Canva or Photopea to apply brand colors and typography.

💻 Web Developers / WP to Astro

Use Case: Migrating a site from WordPress/Elementor to Astro.

Relevant Skills: wp-to-astro-migration, technical-roots-srs

  • Ask the Orchestrator to draft the migration prompt.
  • Trigger the Migration skill. Anti-Gravity will automatically use the DOM scraper utility to pull the site, build the Astro components, and apply Tailwind.
  • Run technical-roots-srs at the end to generate SEO files like robots.txt and llms.txt.

📱 Social Media Team

Use Case: Creating a monthly content calendar.

Relevant Skills: social_media, copywriting

  • Give the Orchestrator your raw ideas or client topic.
  • Trigger the Social Media and Copywriting skills.
  • Anti-Gravity will map out the pillars, write the captions, and even chain the output to the Graphic Design skill to brief the visuals.

🎬 Video Editors

Use Case: Generating an Instagram Reel.

Relevant Skill: Video Editor Remotion

  • Give the Orchestrator your video topic.
  • Trigger the Video Editor skill.
  • Anti-Gravity will draft the teleprompter script, generate voiceovers, and apply CSS patches to your Remotion project.

🛑 5. "I'm Stuck!" (Troubleshooting)

If things aren't going right, check these common issues:

Issue: Anti-Gravity is giving me generic, boring output.

Fix: You probably skipped the Orchestrator. Never ask Anti-Gravity to do the final task immediately. Always ask it to draft the prompt first using the Orchestrator, review the prompt, and then execute.

Issue: Anti-Gravity forgot the brand guidelines or project rules.

Fix: Remind it to read its skills. Say: "Please re-read the [Skill Name] file in the workspace to ensure you are following the SRS standards, then try again."

Issue: The Web Migration isn't matching the design perfectly.

Fix: Ask Anti-Gravity to run the "Phase 4: Exact Visual Parity Audit" from the wp-to-astro-migration skill. Tell it to use the browser_subagent to look at the live WordPress site and compare it to the local code.

Issue: Anti-Gravity says "I don't have access to that tool."

Fix: Some workflows (like opening Canva) require the browser_subagent. If it fails, explicitly tell it: "Use your browser_subagent tool to navigate to Canva.com and execute this."
