# SRS Skills Folder — Square Root SEO

This folder contains the complete set of Antigravity skills for **Square Root SEO (SRS)**. These skills are optimized under the **"Specific Hysterific"** principle—ensuring each agent performs only its specialized task with hyper-specialized scope boundaries.

---

## The "Specific Hysterific" Standard

Every skill in this repository follows a strict **In-Scope / Out-of-Scope** protocol.
- **Goal**: Zero scope creep.
- **Enforcement**: If a task falls outside a skill's defined domain, it MUST be routed through the `@srs-master-orchestrator` to the correct specialized skill.
- **Benefit**: More precise, performant, and reliable agentic outputs.

---

## How to Use

### Step 1 — Copy into Your Project

```
YourProject/
├── .agents/
│   └── skills/
│       ├── graphic_design/SKILL.md
│       ├── punit_tongia/SKILL.md    ← Always import FIRST
│       ├── seo/SKILL.md
│       ├── copywriting/SKILL.md
│       ├── social_media/SKILL.md
│       └── web_dev/SKILL.md
```

### Step 2 — Skill Import Order

Always import **`punit_tongia`** first — it contains the foundational strategy, client discovery protocol, and proprietary frameworks that all other skills depend on.

After that, import department-level skills as needed:

| Skill | When to Use |
|-------|------------|
| `punit_tongia` | **Always first.** Strategy, frameworks, client qualification. |
| `seo` | Technical SEO audits, keyword research, GEO optimization, Schema implementation. |
| `copywriting` | Blog writing, landing page copy, SEO content, AI-safe writing. |
| `social_media` | Content calendars, cross-platform publishing, client reporting. |
| `graphic_design` | Visual assets, AI image generation (native + external), brand guidelines, browser-based Canva/Photopea execution, platform-specific graphics, full delivery pipeline. |
| `web_dev` | WordPress/Shopify builds, speed optimization, technical implementation. |

### Step 3 — Combine Skills for Tasks

Most tasks need multiple skills working together:

- **Writing a blog post** → `punit_tongia` + `seo` + `copywriting`
- **Building a website** → `punit_tongia` + `web_dev` + `seo` + `graphic_design`
- **Social media campaign** → `punit_tongia` + `social_media` + `copywriting` + `graphic_design`
- **Client onboarding** → `punit_tongia` + `seo` + `web_dev`

## Updating Skills

When an SOP changes (new Google algorithm, new tool adopted, new framework developed), update the relevant `SKILL.md` file here. All projects using this folder will inherit the update.
