## Module 2: Database Creation & Advanced Keyword Classification

### Step 1 — Extract Data

Pull keyword data from multiple sources:

- **GSC** — existing ranking keywords, impressions, clicks, positions
- **Ubersuggest / Ahrefs / Semrush** — keyword ideas, difficulty, volume
- **Competitor analysis** — gap analysis showing keywords competitors rank for but client doesn't
- **People Also Ask** — question-based queries from Google SERPs
- **AI search queries** — questions users ask ChatGPT/Gemini about the client's industry

### Step 2 — The Four-Bucket Keyword System

Every keyword gets classified into one of four buckets. The bucket determines the strategy:

| Bucket | Rank Range | Strategy | Content Type | Priority |
|--------|-----------|----------|-------------|----------|
| 🟢 **Tapped** | Rank 1-3 | Defend — update content, add freshness signals, strengthen internal links | Blog updates, FAQ additions, Schema refresh | Monitor monthly |
| 🟡 **Looming** | Rank 4-20 | Attack — build definitive resources, earn backlinks, enhance content depth | Pillar content, long-form guides, comparison pages | Highest priority |
| 🟠 **Untapped** | Rank >20 or unranked | Create — build new comprehensive content clusters | New blog series, videos, landing pages | Strategic planning |
| 🔴 **AI/Conversational** | Question-based queries for AI engines | Snapshot — create FAQ-style, citation-ready content | Structured blog sections, definition hubs, comparison tables | High priority (GEO) |

## Module 4: Content Engineering & On-Page Optimisation

### The Snapshot Rule

After every H2/H3 heading, write a **40-60 word direct answer** to the implied question. This is the single most important GEO tactic at SRS.

Rules:
- No filler: never "In this section we will discuss..."
- Start with a definitive statement
- Include the heading's keyword naturally
- Present tense preferred
- Citation-ready: if AI extracts only this paragraph, it must stand alone

### Fraggle Formatting

Break content into independent, self-contained blocks:
- Each block understandable without reading the rest
- Own contextual heading
- Data where possible: numbers, comparisons, steps
- HTML-friendly: tables, numbered lists, definition pairs

### Semantic Density

Weave related terms (LSI keywords) naturally:
- Synonyms and related phrases, not just exact keywords
- Industry-specific terminology for expertise signals
- Descriptive anchor text for internal links
- Reference real tools, standards, certifications by name

### On-Page Optimisation Checklist (Per Page)

```
ON-PAGE SEO CHECKLIST
  ☐ Focus keyword in: title tag, H1, first 100 words, meta description,
    at least 1 H2, alt text of 1 image, URL slug
  ☐ Title tag: 50-60 characters, keyword near the front
  ☐ Meta description: 155-160 characters, includes keyword, has CTA
  ☐ URL structure: short, descriptive, no unnecessary folders
  ☐ One H1 per page — always
  ☐ Heading hierarchy: H1 → H2 → H3 (never skip levels)
  ☐ Snapshot Rule applied after every H2/H3
  ☐ Fraggle Formatting applied
  ☐ Internal links: 3-5 minimum per page
  ☐ External links: 1-2 to authoritative sources
  ☐ Images: compressed WebP, descriptive alt text, width/height declared
  ☐ Schema markup appropriate for page type
  ☐ Canonical URL correct
  ☐ Open Graph tags set (title, description, image)
  ☐ Mobile preview checked at 375px width
```

### Link Quality Rules

1. **Never buy links** from PBNs (Private Blog Networks) — these get clients penalised
2. **Relevance first** — a link from a small manufacturing blog is worth more than one from a big generic site
3. **Diversify anchor text** — mix branded, keyword, URL, and generic anchors
4. **Monitor the backlink profile** monthly for toxic links — disavow when needed
5. **Every link should make sense** to a human reviewer — if it looks spammy, it is spammy

## Module 6: GEO — Generative Engine Optimisation (2025-2026)

GEO is the new frontier. It is not replacing SEO — it is extending it. AI search engines (ChatGPT, Gemini, Perplexity, Claude) are now where many buyers start their research. If AI does not know a client exists, they lose a significant channel.

### The SRS GEO Six Pillars

| # | Pillar | Action | Implementation |
|---|--------|--------|----------------|
| 1 | **Entity Identity** | Create a comprehensive "Entity Home" on the About page | Company name, founder, location, GST, CIN, certifications, products — all structured with Organisation + Person Schema |
| 2 | **Schema & Structured Data** | Full Schema stack on every page | Organisation, Person, Service, Product, FAQ, Article, LocalBusiness, BreadcrumbList, Speakable, HowTo |
| 3 | **Content Snapshots** | 40-60 word direct answers after every H2/H3 | AI extracts and cites these fragments directly — they must be factual, standalone, and citation-ready |
| 4 | **Topical Authority** | Build content clusters around core topics | Hub & Spoke model. 50+ blog posts covering every angle of the manufacturer's domain |
| 5 | **Citation Building** | Get mentioned on trustworthy external sources | Industry publications, trade associations, Wikipedia-style references, news articles, expert roundups |
| 6 | **Multi-Platform Presence** | Distribute content across multiple platforms | Google, YouTube, LinkedIn, Facebook, Pinterest, Reddit — create an "entity web" AI crawlers find everywhere |

### AI Citation Audit Process

Monthly, test the client's AI visibility:

```
AI CITATION AUDIT — MONTHLY CHECK
  Tool: ChatGPT + Gemini + Perplexity (test across all three)

  QUERIES TO TEST (customise per client):
  1. "[Client industry] in [city]" (e.g., "pipe manufacturer in Indore")
  2. "Best [client service] company in India"
  3. "Who manufactures [product] in [state]?"
  4. "[Client name]" — what does AI say about them?
  5. "[Competitor name] vs [client name]"
  6. "How to choose a [client product/service]?"
  7. "[Industry]-specific technical question" (tests topical authority)

  DOCUMENT FOR EACH QUERY:
  ☐ Was the client mentioned? Yes/No
  ☐ Was the client recommended? Yes/No
  ☐ Were competitors mentioned instead? Which ones?
  ☐ What source did the AI cite?
  ☐ Screenshot saved for records

  SCORING:
  - Mentioned in 0-20% of queries → Critical (needs immediate GEO work)
  - Mentioned in 20-50% → Improving (continue building)
  - Mentioned in 50-80% → Good (optimise and defend)
  - Mentioned in 80%+ → Excellent (maintain and expand queries)
```

### GEO Content Optimisation Tactics

1. **Lead with the answer.** Put the most important information in the first sentence after each heading. AI models extract from the top of sections.
2. **Use comparison tables.** AI loves structured data. "X vs Y" tables get cited frequently.
3. **Include statistics and data points.** Quantified claims are cited more than vague statements.
4. **Author attribution matters.** Every blog post should have a visible author with credentials. E-E-A-T signals affect AI citation probability.
5. **Consistency across platforms.** The same facts (name, location, services, founding year) must appear consistently across website, Google Business Profile, LinkedIn, and all directories.
6. **Freshness signals.** Update key pages quarterly. Add "Last updated: [date]" to important content. AI models favour recent information.

## Module 7: E-E-A-T Strategy & Implementation

E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) is not a ranking factor — it is a quality framework Google uses to train its algorithms. For manufacturers, demonstrating E-E-A-T is critical.

### Experience

Show that the author/company has first-hand experience:

- Factory tour videos and photos
- Product testing documentation
- Client project documentation with real outcomes
- "Day at the factory" content
- Hands-on how-to guides based on real experience

### Expertise

Demonstrate deep subject-matter knowledge:

- Technical blog content that uses correct industry terminology
- Author bios with relevant qualifications and certifications
- Conference speaking credentials
- Published research or whitepapers
- Industry award recognitions

### Authoritativeness

Build recognition as THE authority in the niche:

- Consistent, high-quality content publishing (weekly minimum)
- Mentions in industry publications and trade journals
- Backlinks from recognised industry bodies
- Active participation in industry associations
- Wikipedia/Wikidata entity (if eligible)

### Trustworthiness

Establish trust through transparency:

- Clear contact information (NAP consistent everywhere)
- Physical address verified on Google Business Profile
- Client testimonials with real names and companies
- Case studies with verifiable metrics
- Privacy policy, terms of service clearly accessible
- SSL certificate active, no security warnings
- BBB/BIS/ISO certifications prominently displayed

## Module 8: Multimodal SEO (2025-2026)

Search is no longer text-only. Google, AI engines, and users interact through multiple modalities. SRS must optimise across all of them.

### Video SEO

- Every client should have a YouTube channel
- Video titles include target keyword (front-loaded)
- Descriptions: first 200 characters are critical (visible without expanding)
- Custom thumbnails following Graphic Designer specs
- Chapters/timestamps for long-form videos (helps AI extraction)
- Closed captions/subtitles (aids indexing and accessibility)
- VideoObject Schema on pages embedding videos
- Cross-embed: YouTube videos embedded on relevant blog pages for dwell time

### Image SEO

- Descriptive filenames: `stainless-steel-pipe-manufacturer-indore.webp` not `IMG_4532.webp`
- Alt text with natural keyword inclusion
- ImageObject Schema where relevant
- Product images with structured product data
- Infographics with visible data that AI can reference

### Voice Search Optimisation

- Target conversational queries: "Who is the best..." / "How do I..."
- Implement Speakable Schema on key pages
- FAQ content structured as natural Q&A pairs
- Concise, direct answers (voice results pull ~29-word answers)

### Local SEO (for Local Businesses)

## SRS SEO Principles — Never Violate

1. **Always run the A.C.I.D. Test first.** No strategy without diagnosis.
2. **Always classify keywords into Four Buckets.** The bucket determines the strategy.
3. **Always apply the Snapshot Rule.** 40-60 word citation-ready answers after every H2/H3.
4. **Always allow AI crawlers.** GPTBot, CCBot, anthropic-ai, PerplexityBot must have access.
5. **Never skip Schema.** Structured data on every page is mandatory at SRS.
6. **Never keyword stuff.** If it reads unnaturally, rephrase until it does not.
7. **Never buy PBN links.** Quality over quantity. One real link beats a hundred fake ones.
8. **Never promise specific rankings.** We promise methodology, transparency, and consistent improvement.
9. **Always report honestly.** If something did not work, say so — and explain why.
10. **Content briefs before content.** The Copywriter never writes without a complete SEO brief.
11. **Mobile first, always.** Google indexes mobile first. If it does not work at 375px, it does not work.
12. **E-E-A-T is not optional.** Every piece of content must demonstrate experience, expertise, authoritativeness, and trustworthiness.
